# Contributing

Bug reports and reproducibility issues are welcome. Please use the GitHub issue templates and include: operating system, Python version, dependency installation method, exact command, complete error message, and whether third-party source data were used.

Do not upload restricted or participant-level third-party datasets to issues or pull requests.

Scientific changes that alter headline results should not silently overwrite `v1.0.0`; use a new semantic version and document whether the scientific result set changed.
