# Source data acquisition

Raw third-party participant data are **not redistributed** in this repository. The code expects source files obtained from the original publications/repositories under their original access and license conditions. Derived, project-authored result tables needed to inspect the article-linked conclusions are in `../results/`.

See `../THIRD_PARTY_DATA_NOTICE.md` for source-by-source acquisition details and redistribution boundaries.

The restricted Zhou et al. participant-level workbook is not included. Only derived longitudinal summaries and provenance are distributed.
