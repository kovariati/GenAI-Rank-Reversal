# Changelog

## 1.0.0 — 2026-09-19

Publication-linked release for the peer-reviewed article **Kovari, A. (2026), _Generative AI, Performance, and Learning: A Framework for Comparing Interventions Across Assessment Regimes_, Computers, 15(9), 633**, DOI `10.3390/computers15090633`.

- Synchronized final journal, DOI, publisher, publication-date, and bibliographic metadata across the README, CFF, BibTeX, RIS, CodeMeta, Schema.org JSON-LD, `llms.txt`, and GitHub discovery surfaces.
- Established `v1.0.0` as the publication-linked software/reproducibility release identity.
- Added the versioned results asset `GenAI_Rank_Reversal_results_v1.0.0.zip`, containing the canonical `results/` directory.
- Retained the corrected task-specific Wong–Qiu inference, two-orientation multiplicity handling, elaboration sensitivity family, construct-commensurability gate, ARRP specification checks, evidence-synthesis audit, and deterministic repository validation.
- Added publication-day repository settings and social-preview assets.
- No custom checksum/hash manifest is distributed and release immutability is intentionally not enabled.
- No third-party raw participant data are redistributed.

## Publication-candidate packaging — 2026-09-15

The public tree was reduced to the research software, derived results, reproducibility documentation, and public metadata needed for publication. File-identity inventories, auxiliary checksum artifacts, graphical-abstract files, caches, and internal development material were excluded. The release strategy was simplified to a tagged source snapshot plus one downloadable results asset.

## Final manuscript alignment — 2026-09-14

The title, abstract, keywords, outcome scope, and repository documentation were aligned with the final methodological framing. The focal report was restricted to task-specific originality with orientation-aware multiplicity handling, while usefulness was retained as secondary corroboration and elaboration as a sensitivity family. Construct-commensurability rules, ARRP validation, raw-data boundaries, and deterministic software tests were also finalized.
