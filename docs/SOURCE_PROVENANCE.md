# Source provenance and redistribution boundaries

The detailed source-provenance tables are repository artifacts rather than journal appendices.

## Canonical files

- `results/source_provenance_master.csv` — master provenance inventory for project inputs and derived objects.
- `THIRD_PARTY_DATA_NOTICE.md` — third-party acquisition and redistribution boundaries.
- `DATA_AVAILABILITY.md` — public data/code availability statement.
- `results/zhou_source_provenance.json` — provenance record for the restricted Zhou extension.
- `results/evidence_map_study_inventory.csv` — study-level evidence-map inventory.

The master provenance table contains 106 objects in the current audited state. Third-party raw data are not relicensed by this repository. Restricted or non-redistributable source records remain excluded.
